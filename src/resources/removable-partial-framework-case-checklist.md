The technician receives a model or scan, but the clinical decisions that guide a removable partial framework belong in the prescription. A clear handoff helps the clinic and laboratory agree on the design before producing metal.

## Include the design instructions with the model

- Name the arch and teeth to be replaced. Identify any planned changes to the remaining dentition that affect the design.
- Attach the clinician's design or marked model when available. Record any specified rests, clasp positions, major connector or areas that should be relieved.
- Identify the model or scan and provide the opposing arch or bite record when the requested work requires it.
- Describe the requested stage, such as framework only, framework try-in or a complete appliance. Add shade and mould details when tooth setup is included.

## Agree on the review step

A drawing and a scan can disagree. For example, a clasp on a drawing may refer to an earlier version of the model. Use matching case IDs and label the current records so the lab can raise questions against the right version. If a framework try-in is planned, record who will approve it and how adjustments should be reported before the acrylic stage.
